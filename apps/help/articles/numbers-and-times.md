BitGigs uses **Danish number format** everywhere: a comma is the decimal
separator and a dot groups thousands — `1.234,56`. Type numbers the same way
in forms: `7,5` hours, `142,50` kr. Amounts are always DKK.

## Time fields

Every time field is a **24-hour** input with an hour and a minute segment,
regardless of your browser's language — `16:30`, never `4:30 PM`. They're
built for the keyboard:

- Type the hour digits and the cursor **advances to minutes by itself** —
  `1630` gives `16:30` in four keystrokes.
- **←/→** move between hour and minutes; **↑/↓** nudge the highlighted
  segment up or down.

> Tip: on the planning calendar you can skip typing times entirely — set a
> default shift per workplace and stamp it with
> [Power Edit](/help/a/power-edit/).

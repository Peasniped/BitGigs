Two ways to fill a fresh install.

## Import an export file

Already used BitGigs somewhere else? Take the JSON file from that install's
**Data › Export** and upload it here. Your workplaces, pay terms, shifts and tax
details come across as they were, so there's nothing to retype.

You'll see exactly what the file contains and confirm before anything is saved.
Once confirmed, the data is written and you land on
[Review](/help/onboarding-review/).

A file doesn't have to cover everything. An export made without tax details, for
example, still brings your workplaces — Review then asks for the missing piece,
and you can either import a second file or fill it in by hand.

## Set up from scratch

Walks you through the tax profile, your first workplace and its pay terms — three
short steps. Nothing is written until you press **Finish** on Review.

## You aren't locked in

The choice only decides where **Continue** goes. Both routes stay open: you can
import after starting by hand, or type in whatever an import didn't cover. Come
back to this step any time from the step circles at the top.

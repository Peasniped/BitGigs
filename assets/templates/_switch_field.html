{% comment %} Render a form BooleanField as an accent on/off switch — the reusable "custom on-off" for boolean *settings* (not selection checkboxes). Usage: {% include "_switch_field.html" with field=form.some_bool %} The input keeps the form's own id/name, so page JS keyed on `id_` still works. Pass `wrapper_class` to override the default spacing, and `autosave` with a scope key (core.settings_fields.SCOPES) to make it save on change with no Save button — see the autosave convention in CLAUDE.md. Help text sits *inside* the check by default, indented under the label, which is what a switch with its own follow-on content wants (Display's mask-money preview lines up with it via `ms-4`). Pass `help_outside` on a pane whose other hints start at the left margin — the Calendar tab hand-renders its personal- calendar hint that way, and one indented paragraph among them reads as a stray indent rather than as a switch. {% endcomment %}
